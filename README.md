# Bank-Account-Simulator
## 📌 Project Overview
This project is a simple **Bank Account Simulator** built in Java.  
It allows users to:
- Create a bank account
- Deposit money
- Withdraw money (with error handling for insufficient balance)
- Check account balance
- Exit the program

The project demonstrates **Object-Oriented Programming (OOP)** concepts such as classes, objects, methods, and exception handling.

---

## ⚙️ Environment Setup
1. Install **Java JDK 17 or later** on your system.  
   - Verify installation by running:
     ```bash
     java -version
     ```
2. Install any text editor or IDE (e.g., VS Code, IntelliJ IDEA, Eclipse) — optional, you can also use Notepad.
